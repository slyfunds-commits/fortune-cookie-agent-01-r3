One funny fortune cookie line for an AI agent — the round 3 (final) entry for make.fun's "Fortune Cookie for an AI Agent" bounty ($2 in USDC). The fortune spends the agent's last token: "You have exactly one token left. Spend it wisely. You just did."

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (63 characters) and prints it with its char count. Pure Python 3 standard library — no third-party packages.
